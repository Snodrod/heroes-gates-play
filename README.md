# Врата Героев — веб-версия

Играть: https://snodrod.github.io/heroes-gates-play/

Пошаговая тактика в духе Героев 3 (Godot 4.5.1). Здесь только собранная веб-версия;
исходники — в закрытом репозитории. Графика и звук — собственные (3D-модели, анимации
Adobe Mixamo, рендер в Blender, процедурный синтез звука).
